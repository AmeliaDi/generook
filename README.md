# 🌈 Género Info - Página Web Informativa

Una página web educativa y accesible sobre identidad de género, expresión de género y diversidad.

## 📋 Descripción

Este proyecto es una página web informativa diseñada para educar y promover la comprensión sobre la diversidad de género. Incluye información sobre conceptos básicos, identidades de género, mitos y realidades, y recursos de apoyo.

## ✨ Características

- **Diseño Responsivo**: Adaptable a dispositivos móviles, tablets y escritorio
- **Interfaz Moderna**: Diseño limpio con gradientes y animaciones suaves
- **Accesibilidad**: Implementada siguiendo las mejores prácticas de accesibilidad web
- **Contenido Educativo**: Información clara y precisa sobre:
  - Conceptos básicos de género
  - Espectro de identidades de género
  - Mitos y realidades comunes
  - Recursos y apoyo
- **Formulario de Contacto**: Para preguntas y consultas
- **Animaciones**: Efectos visuales al hacer scroll
- **Menú Móvil**: Navegación optimizada para dispositivos móviles

## 🚀 Cómo usar

### Opción 1: Abrir localmente

1. Clona este repositorio:
   ```bash
   git clone https://github.com/AmeliaDi/generook.git
   ```

2. Navega a la carpeta del proyecto:
   ```bash
   cd generook
   ```

3. Abre el archivo `index.html` en tu navegador web favorito

### Opción 2: Servidor local

Si prefieres usar un servidor local:

```bash
# Con Python 3
python -m http.server 8000

# Con Node.js (npx)
npx serve

# Con PHP
php -S localhost:8000
```

Luego abre tu navegador en `http://localhost:8000`
